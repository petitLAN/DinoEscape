## 📦 Downloads

### 🌐 Standalone HTML — open directly in your browser

[![Download Standalone HTML](https://img.shields.io/badge/Standalone%20HTML-Download-2ea44f?style=for-the-badge&logo=html5&logoColor=white)](https://github.com/petitLAN/DinoEscape/releases/download/V1.1/Piertjes-verjaardagsavontuur-v1.1.html)

### 🛠️ Complete project — run with `start.bat`

[![Download Project ZIP](https://img.shields.io/badge/Complete%20Project-Download%20ZIP-0969da?style=for-the-badge&logo=github&logoColor=white)](https://github.com/petitLAN/DinoEscape/archive/refs/tags/V1.1.zip)

Contains the full project files for local hosting or further development.

1. Download the ZIP file and extract it.
2. Open the extracted project folder.
3. Run **`start.bat`** on Windows to start the local server.
4. Open the local address shown by the launcher if it does not open automatically.
